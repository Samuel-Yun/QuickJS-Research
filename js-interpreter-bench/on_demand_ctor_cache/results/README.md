# 已有结果

这些 CSV 原样复制自冻结方法的历史实验，没有混入新基准入口联调产生的计时：

- `octane.csv`：17 个表项；`candidate_ms` 是按需构造缓存。
- `sunspider.csv`：26 个表项，列含义相同。
- `memory_work.csv`：独立计数构建得到的模板解析、负命中和记录请求字节。
- `historical_results.md`：当时的完整报告，保留旧技术名称和原复现命令作出处。

| 整体耗时变化 | 按需构造缓存 / A | V8_ON --jitless / A |
|---|---:|---:|
| Octane，14 suite 分层等权几何平均 | −7.86% | −39.80% |
| SunSpider，26 项等权几何平均 | −4.45% | −31.00% |

方法为历史单轮，A/V8 为先前 30 轮中位数，属于**跨批次单轮筛选**。耗时负数更快。完整版本相对 A 的变化包含此前积累的优化；最后一层相对 R3 的旧单轮变化为 Octane −0.89%、SunSpider −0.84%。

`memory_work.csv` 的记录字节是诊断累计位点数乘 Release 结构体尺寸，不是 RSS；计数构建有额外诊断指针，其覆盖不能直接当成 Release 计时进程的覆盖。白盒命中率实验另见原 `sparse_whitebox_20261116/attempt01`，不混入这里的全集时间表。
