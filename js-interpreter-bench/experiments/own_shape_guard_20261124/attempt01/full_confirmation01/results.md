# OWN_SHAPE_GUARD：同批单轮全集

只纳入通过事先定下的定向重复筛选的候选。SPARSE 基线现场新测；每版每项一个新进程，版本顺序随表项轮换。沿用冻结脚本、输入、N、校验、Setup/Run 边界，首个 Run 计入，无额外热身；CPU 2、Asia/Shanghai、C locale。

负数是耗时下降。Octane 按 14 suite 分层等权 GM，SunSpider 按 26 项等权 GM；单轮筛选，不报显著性，不替换默认版。
