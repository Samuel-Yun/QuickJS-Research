# 三种执行路径实验：完整基准

每个新候选每项一个新进程，按测试项轮换版本顺序，沿用冻结原脚本、输入、N、校验、Setup/Run 边界、首个 Run 计入，无额外热身，CPU 2 / Asia/Shanghai / C locale。
按用户要求，不重跑 A/SPARSE/V8 全集。A/V8 沿用 03_sparse_ctor/analysis 中 native_confirmation 的 30 进程中位数；父版 SPARSE 使用最近已有的 own_shape_guard/full_confirmation01 中同一冻结源码的现场单轮，避免拿更早、差异更大的父版时间归因新优化。旧已发表 SPARSE 时间也保留在 CSV 的 SPARSE_published_ms 列，不覆盖旧记录。因此新候选与它们的全集比较是跨批次筛选。定向 5 对现场 SPARSE 对照另列，不能用历史父版代替它。
V8_ON 历史参数为 --jitless --no-lazy --use-ic。括号相对历史冻结 SPARSE，负数更快；CSV 另附相对 A、V8 的变化。Octane 按 14 suite 分层等权 GM，SunSpider 按 26 项等权。
