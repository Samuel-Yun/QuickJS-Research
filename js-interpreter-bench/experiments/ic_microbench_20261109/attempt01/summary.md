# 可控属性读取微基准：原版 A 时长验收

使用此前 30 轮确认中的原版 A ELF，固定 CPU 2，循环 201,326,592 次。
每种设置单独启动一个进程、测一次；126 个短正确性检查通过。
**七种设置的实际读取循环均严格超过 3 秒。**

| 目标命中率 | 模型命中率（含冷启动） | 原版 A 耗时（秒） |
|---:|---:|---:|
| 0% | 0.000000000% | 4.8733 |
| 25% | 25.000000000% | 4.9138 |
| 50% | 50.000000000% | 4.9832 |
| 75% | 75.000000000% | 4.9310 |
| 90% | 89.999389648% | 4.9296 |
| 99% | 98.999023438% | 4.9608 |
| 100% | 99.999999503% | 4.8679 |

命中率为单形状 IC 的模型推算；原版 A 没有该 IC，尚未采集优化版真实命中计数。
本次仅验收程序与时长，不能用这些单次 A 数据判断 IC 的收益。
计时只包含 readLoop 调用，排除对象/序列构造及模型计算；包括循环、数组取对象、属性读取和累加。
使用 CLOCK_MONOTONIC，无工作负载预热；checksum 全部为 603,979,776。

原始输出见 `A.hit*.stdout`，命令/进程返回码见 `A.hit*.process.json`，
参数和 SHA 见 `manifest.json`，结构化数据见 `results.json`。
`inputs/` 另存本次验证代码的逐字节副本，其 SHA 与 manifest 一致。
