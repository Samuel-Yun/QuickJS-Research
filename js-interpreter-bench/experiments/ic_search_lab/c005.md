# c005：12字节热记录＋独立冷atom区（parent=M）

M每读点16字节，把命中不需要的atom和shape/offset放在同一数组；较多读点时热扫描包含冷字段。
本候选在同一块分配内先放packed的12字节shape+offset数组，后放4字节atom数组；函数头增加一个冷数组指针，存取、保存加载及释放同步使用该指针，命中守卫/准入不变。
预计热数组footprint低25%，但总请求的逐site字节仍16、函数头多8字节；奇数记录的shape读取未按8字节对齐，miss多一次冷指针读取。限定当前GCC/x86_64，不预设更快。除最小回归，必须在初筛前通过实际保存/加载、OOM、GC及qjsc嵌入检查。
