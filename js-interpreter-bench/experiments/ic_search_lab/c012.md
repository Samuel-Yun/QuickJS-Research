# c012：按已有shape引用计数保留锚点（parent=M）

M总替换新shape；c010的只填一次策略又可能锁在无其它引用的旧shape。
本候选在旧shape的`js_rc(shape)->ref_count>1`时保留锚点，否则沿用M替换；不删精确shape、class、descriptor及生命周期条件，失配仍普通读取当前值。
预计减少部分替换，同时新增一次refcount读取；其它IC也可能持有shape，refcount不能解释为对象数量，更不能宣称测到了完整shape多样性。

已在实施前核对当前版本：quickjs.c的js_rc约1501行、js_dup_shape约5303行使用分配块前缀中的ref_count，JSShape.header是GC链头，不把旧版结构印象写入实现。这里只读既有计数，不修改分配器或GC。
