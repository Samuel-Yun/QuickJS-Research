# s004 / parent M：shape内验证过的正查找hint

原M只加速一部分named read，普通miss及其他helper仍调用find_own_property；本候选在当前JSShape内存上次成功下标，核对范围、非NULL atom与当前entry.atom后返回当前descriptor/prop，不缓存值、prop地址或外部shape指针。
失败仍走原hash链，找到才更新hint；克隆/压缩后的旧下标仍须当前entry验证。delete_property在unlink之前无效化hint，保护free_property原生finalizer重入窗口；新增字段在new_shape_nohash初始化，复制沿原形状复制路径，GC无新增边，磁盘格式不变。
可能减少同shape同字段的后端重复hash读取，也可能因交替字段、额外检查/写入、shape增大和删除维护退化。它不是P容量变体、R退出或E原型/store扩展；M前端IC完全保留。这里只修改find_own_property，不覆盖find_own_property1或所有数组/元素快路。
