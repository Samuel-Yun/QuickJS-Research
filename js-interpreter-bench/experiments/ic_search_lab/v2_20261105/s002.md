# s002 / parent M：函数级固定总预算shape+atom表

原M每个最终读点都有16字节热记录和独立shape强引用；本候选让site只存atom，所有点共用每函数8-entry直接映射表，key必须同时匹配当前shape及atom。
命中仍保留object/class/non-exotic/exact-shape保护并读当前值；miss完整查找、准入后发布entry，先retain新shape再释放旧shape。metadata+table同块分配，GC/free跟随8条entry，atom仍由每个site单独拥有。
预计减少大函数的重复记录/shape维护，增加hash、冲突、共享状态与小函数固定128字节table成本。旧NG是每atom各一组shape，本方案是所有atom/位置竞争一个函数总预算；不是仅把P改成8槽。
