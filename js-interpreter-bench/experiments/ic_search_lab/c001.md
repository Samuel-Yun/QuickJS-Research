# c001 / parent M：同offset失配时保留旧shape锚点

原M的rdi_update在合格own-data miss后，即使新旧字段下标相同，也dup新shape、free旧shape并替换缓存。c001仅在shape不同、已有非空槽且已验证offset相同时返回，仍由正常miss body返回本次新对象的当前属性值；精确shape命中守卫完全不变。预计减少部分替换/引用维护，可能失去后续新shape稳定命中、增加普通查找，额外增加一个更新端条件分支。

改动：`active/read_ic_runtime.inc:rdi_update`，仅RDI_CAPACITY==1分支。
不缓存属性值，不沿用旧prop指针，不忽略描述/准入检查；不按Splay或任何PC选择。
同offset不是读取许可，只是是否替换缓存的策略。此策略仍可能明显退化，需新数据检验。
