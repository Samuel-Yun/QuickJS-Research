# 用户授权的受限探索批次（不追溯改变旧结果）

用户于本轮明确要求“能否忽略这个计时，继续执行”。据此不改系统设置，保留原
CLOCK_MONOTONIC、冻结二进制、完整N和计时边界，只把UTC/RAW交叉差异降为警告。
适用范围是 `V7_WARN_CLOCK=1`、独立epoch的新批次；原STOP及隔离数据不动。

该模式质量标签 `EXPLORATORY_CLOCK_LIMITED`，不宣称计时已经可靠，不据约1%的
点估计确认性能收益。即使给出探索性bootstrap，它也不包含系统时钟误差，不能
修复该限制。可用于执行流程、正确性与大信号候选的初步筛选。

继续保留硬门槛：boot不变、源码/制品/输入身份、退出码、checksum、内部时间
为正且被外部单调区间包住、无并行构建与采样。实际异常和慢样本均保存。
未授权修改WSL时钟源、校时服务、Windows或其他系统设置。
