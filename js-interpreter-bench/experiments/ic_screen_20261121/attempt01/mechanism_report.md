# 机制计数：确实少做了什么

所有计数来自独立插桩构建，不使用其耗时评价性能。构造小用例每组 65,536 次，循环只有一个 new 位点，序列生成在循环外；各版脚本、参数和结果校验相同。

## C/D 交替：解析、遍历与发布

| 版本 | 正命中 | 模板解析 | 模板复用 | 正计划发布 | 原型层访问 | 描述符查询 | 扩展分配 / 字节 |
|---|---:|---:|---:|---:|---:|---:|---:|
| SPARSE | 0 | 131071 | 0 | 65535 | 524280 | 524280 | 0 / 0 |
| M1 | 0 | 65536 | 65535 | 65535 | 524280 | 524280 | 0 / 0 |
| M2 | 0 | 131071 | 0 | 65535 | 262140 | 524280 | 0 / 0 |
| P2 | 65533 | 5 | 0 | 2 | 262148 | 262148 | 1 / 16 |
| P3 | 65533 | 5 | 0 | 2 | 262148 | 262148 | 1 / 24 |
| P4 | 65533 | 5 | 0 | 2 | 262148 | 262148 | 1 / 32 |
| D16 | 0 | 131071 | 0 | 65535 | 524280 | 524280 | 0 / 0 |

M1 在这组输入把模板解析从 131,071 次减为 65,536 次，正计划仍发布 65,535 次。M2 把原型层访问从 524,280 次减为 262,140 次，描述符查询仍是 524,280 次。多槽在容量内主要省的是反复学习：C/D 交替只发布两份计划，此后基本命中。

新增成本也保留在实验里：M1 的失配路径多一次 C 函数调用，并在这个慢路径栈帧中暂存模板和证明信息；命中路径不放这份临时对象。M2 需要用 pending 位图跟踪哪些字段已经找到最近描述符；它省掉重复走层，却没有省掉本组输入的描述符查询。

## D16：进入执行的实际镜像

每个函数的实际 byte_code_buf 在首次进入解释执行时扫描一次。分母是这些字节码实例中的 get_field_rdi 位点（D16 包含短版）；同一函数反复调用不重复计数，eval 创建的新字节码实例分别计数。IC[0] 是记录编号；这里统计的 delta 是指令操作数地址到 ReadICSite 的字节距离。

| 套件 | 原 SPARSE 位点 | ≤255 的比例 | ≤65535 的比例 | D16 短位点 / 全部位点 | 短位点比例 |
|---|---:|---:|---:|---:|---:|
| octane | 253319 | 28.86% | 99.99% | 16195 / 253319 | 6.39% |
| sunspider | 2422 | 46.74% | 100.00% | 21 / 2422 | 0.87% |

| 套件 | 进入执行的镜像代码节省字节 | 对齐后链接镜像节省字节 | 短指令直接执行 | 短指令融合命中 |
|---|---:|---:|---:|---:|
| octane | 32390 | 31536 | 39350781 | 89076572 |
| sunspider | 42 | 56 | 80640 | 22272 |

| 套件 | SPARSE malloc 请求字节总量 | D16 malloc 请求字节总量 | 变化 | SPARSE / D16 realloc 请求字节 |
|---|---:|---:|---:|---:|
| octane | 26535164678 | 26576932614 | +0.1574% | 10966993365 / 10967152785 |
| sunspider | 71737334371 | 71737225367 | -0.0002% | 16111266072 / 16111240818 |

总分配列是 js_malloc_rt 的累计请求字节，不是 RSS 或峰值；realloc 的请求总量另列。镜像省下的字节按实际布局直接计算，不把它当作同等比例的速度收益。

D16 不缩短含跳转/异常入口或非普通函数的字节码；这类排除记录在 d16_excluded_control。调试 PC 在查行号时映射回原宽字节码位置；保存时展开为原格式，加载后再准备。保守选择 delta 并核对最终布局，装不下时保持宽格式；8 bit 只统计。没有保留一份宽镜像副本，也没有为每个函数新增映射旁表。

D16 的融合入口需要判断下一条读取使用短还是宽格式，再选择读取距离和跳过长度。这笔格式判断成本也进入正式 Release；没有关闭融合来绕过它。

完整逐项计数见 `mechanisms/real.json`，微测试原始计数见 `mechanisms/micro.csv`；每个计数进程的命令、输出和退出状态在 `mechanisms/runs.jsonl`。
